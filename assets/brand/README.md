# Original brand assets

This folder preserves SportHub's original brand assets and local font files. See the repository-level [asset catalog](../../docs/asset-catalog.md) and [usage guidelines](../../docs/usage-guidelines.md) before using or exporting them.

## Marks

- `sporthub-wordmark.svg` — primary mark for light surfaces.
- `sporthub-wordmark-reversed.svg` — reverse mark for Dugout Navy/dark surfaces.
- `sporthub-softball-lockup.svg` — softball product lockup.
- `sh-monogram.svg` and `sh-monogram-reversed.svg` — compact app/navigation mark only.
- `softball-hitting.svg`, `softball-pitching.svg`, and the RealBall PNGs — supporting softball artwork.
- `fonts/` — self-hosted Barlow and Inter WOFF2 files with their OFL notices.

The SVG marks reference the neighboring `fonts/` directory. Preserve that relative layout when using these source files.
